# la-uv-anomaly-analysis
Analyzing UV level trends in Los Angeles using satellite data (DISCOVR EPIC, MERRA-2) with AI-powered insights via Claude API

## Overview

This project analyzes UV levels in Los Angeles from 2020-2026 to investigate whether recent UV spikes are anomalous compared to historical trends, and explores correlations with atmospheric factors.

**Key Features:**
- Downloads satellite data from NASA (DISCOVR EPIC, MERRA-2)
- Analyzes UV trends and identifies anomalies
- Correlates UV with atmospheric optical depth
- Uses Claude API to synthesize findings and explore causation

## Data Sources

- **DISCOVR EPIC UV Aerosol** (2015-Present): Daily UV index measurements
- **MERRA-2 Aerosol Optical Depth** (1980-Present): Atmospheric aerosol data
